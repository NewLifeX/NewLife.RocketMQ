NewLife.RocketMQ es un cliente RocketMQ totalmente administrado para Apache RocketMQ y Alibaba Cloud, con mensajes normales, ordenados, transaccionales y diferidos.

## Instalación

```bash
dotnet add package NewLife.RocketMQ
```

## Inicio rápido

```csharp
var mq = new RocketMQClient("127.0.0.1:9876");
mq.Start();
mq.Send("TopicTest", "hello".GetBytes());
```

## Características

- Amplia cobertura de versiones de protocolos y formatos
- Compatible con servicios cloud y middleware gestionado
- Probado en entornos de producción de larga duración
