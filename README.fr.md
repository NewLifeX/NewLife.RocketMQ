NewLife.RocketMQ est un client RocketMQ entièrement managé pour Apache RocketMQ et Alibaba Cloud : messages normaux, ordonnés, transactionnels et différés.

## Installation

```bash
dotnet add package NewLife.RocketMQ
```

## Démarrage rapide

```csharp
var mq = new RocketMQClient("127.0.0.1:9876");
mq.Start();
mq.Send("TopicTest", "hello".GetBytes());
```

## Fonctionnalités

- Large couverture des versions de protocoles et formats courants
- Compatible avec les services cloud et middlewares managés
- Éprouvé en production sur le long terme
